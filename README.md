> 赛事：全国大学生物联网设计竞赛

> 平台：RDK X5 / L610  
> 团队：V我50吃蛋挞 · 南京信息工程大学  

## 📖 作品简介
“鹰隼”是一套面向智慧交通场景的智能车载动态违规稽查系统。项目以 RDK X5 为边缘计算核心，通过前视摄像头实时采集道路画面，结合 YOLOP 与 YOLOv8 等视觉算法，对车辆、车道线及道路目标进行识别，实现实线变道、变道未打灯、车窗抛物和应急车道占用等违规行为检测。系统采用“本地识别、事件驱动、按需上传”的设计方式，在车端完成违规判断与证据生成后，通过广和通 L610 4G 通信模块将违规类型、时间、位置和证据图像上传至云端，并通过微信小程序完成事件查询、证据查看和地图定位。项目构建了“车载感知—边缘计算—无线传输—云端管理—移动端展示”的完整物联网闭环，使车辆能够成为移动智能感知与取证节点。

## 🧠 核心功能
- 基于 YOLOP 与 YOLOv8 的道路环境感知与车辆目标检测，实现实线变道、变道未打灯、车窗抛物和应急车道占用等违规行为识别。
- 基于 RDK X5 完成边缘侧智能推理与违规事件生成，通过三连拍证据链、目标跟踪和事件去重机制提升违规取证完整性。
- 通过广和通 L610 4G 模块将违规事件上传至云端，并结合微信小程序实现违规记录查询、证据展示、位置查看和地图导航。

## 🏗️ 系统架构

系统整体分为车载边缘端、网络传输层和云端业务层。

```text
前视摄像头
    │
    ▼
RDK X5 边缘计算平台
    │
    ├── YOLOP：车道线 / 可行驶区域识别
    ├── YOLOv8：车辆 / 抛物目标检测
    ├── 目标跟踪与违规行为判断
    └── 三连拍证据链生成
    │
    ▼
L610 4G 通信模块
    │
    ▼
云端服务器
    │
    ├── 违规事件存储
    ├── 图片与结构化数据管理
    └── API 服务
    │
    ▼
微信小程序
    ├── 违规事件查看
    ├── 证据图片展示
    └── 地图定位与导航
